# Rakesh Kumar — Cinematographer & Visual Storyteller

A responsive portfolio featuring Rakesh's photography, cinematography, video editing, and graphic design work.

## View locally

Open `index.html` in a browser. Keep `styles.css`, `portfolio-features.css`, `script.js`, `gallery-images/`, and the two portrait images beside it so all page assets load correctly.

The site includes a one-photo-at-a-time gallery, an auto-playing photo reel, a WhatsApp contact shortcut, and a feedback form that opens a prefilled WhatsApp message. Feedback is only marked as shareable when the client checks the permission box.

The gallery contains optimized images for web display. Original high-resolution uploads remain in the local project folder and are excluded from this repository.
